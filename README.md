# CIMSS 2027 Website

Official website for the 7th International Workshop on Critical Infrastructure and Maritime Systems Security (CIMSS 2027), held in conjunction with ACNS 2027.

## Quick Start

### Prerequisites

- Node.js 18 or later
- npm

### Installation and local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser. Changes to the source files are reflected automatically during development.
